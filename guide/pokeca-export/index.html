STEP 01ChatGPT / Claude

チャットAI — 出品の文章を、AIに作ってもらう

このステップでできるようになること

  • 商品の情報を渡して、英語の出品文のたたき台を作ってもらえる
  • バイヤーへの返信も、AIに下書きしてもらえる

なぜ「出品の文章」から始める？

ポケカの海外販売で、いちばん時間がかかるのが「出品文」と「バイヤーとのやり取り」。ここをAIに手伝ってもらうと、効果がすぐ目に見えます。まずは「聞く・お願いする・直してもらう」を体験して、「AIに指示を出す」感覚をつかみましょう。ここをつかんでおくと、このあとが全部ラクになります。

💬 このステップで使うAI
ChatGPT か Claude、まずはどちらか1つでOK。下のボタンから開けます。アカウントがない場合は、画面の案内に沿って、無料で登録できます（2026年時点）。
ChatGPTを開くClaudeを開く

やってみよう｜プロンプト例5つ

使い方は、この3ステップです

① 下のカードの「コピー」を押す
② AIの入力欄に貼り付ける（Macは Command＋V、Windowsは Ctrl＋V）
③ （　）の部分を、ご自身の内容に書き換えて、送信する

上から順に、コピペして試すだけでOK。出てきた文章を「もう少し短く」「もっと丁寧に」と口語で直していくのが本番です。

① 英語の出品文のたたき台
次の情報から、海外のバイヤー向けの英語の出品文を作って。
・カード名：（例：リザードンex）
・状態：（例：未開封／美品／傷あり）
・言語：日本語版
・特徴：（例：レアリティ、パック名、注意点）
丁寧で簡潔に。傷や状態は、正直に書いて。
② 状態の説明を、伝わる英語にする
次の日本語の状態説明を、海外のバイヤーに誤解なく伝わる英語にして。
「（ここに状態の説明を貼る）」
むずかしい言葉は、やさしい英語に言い換えて。
③ バイヤーからの質問に返信
海外のバイヤーから、こんな質問が届いた。丁寧な返信の下書きを、英語で作って。
質問：「（ここに質問を貼る）」
こちらの回答：（例：発送は3日以内、追跡番号つき）
④ 発送のお知らせ
商品を発送したことを伝える、短い英語のメッセージを作って。
追跡番号：（ここに記入）
お礼の一言を入れて、親しみやすく。
⑤ 英語のメッセージを日本語で確認
次の英語のメッセージを、日本語に直して、要点を3つにまとめて。
「（ここに英文を貼る）」

つまづきポイント＆コツ

  • 「英語で書いて」だけ → 毎回、文章がバラバラに
  • 状態（傷・白かけなど）をAIの推測にまかせる → 実物と違う説明になることも

⭕ 「誰に・何を・どんな口調で」を1〜3行で添えると安定。状態は、ご自身の目で確認した内容をそのまま渡しましょう

こんな答えが返ってきます（イメージ）「Charizard ex（日本語版）／状態：未開封、角に目立つ傷なし。丁寧に梱包して、追跡つきで発送します。」のような、出品文のたたき台が出ます。気になるところは「もう少し短く」と、続けて頼めばOKです。
STEP 02ChatGPT / Claude

アイデア整理 — 「やりたいこと」を言葉にする

このステップでできるようになること

  • 日々の業務を、AIと一緒に洗い出せる
  • 「ここをAIに任せたい」の候補が、リストになる

なぜ、整理から？

AIをうまく使うコツは、「何をやりたいか」を、ご自身の言葉にすること。ここがいちばんの出発点です。日々の業務の中で「面倒だな」「こうできたらいいな」と思った瞬間を、メモしておくと、次のステップでそのまま材料になります。

（ここに、1日の流れを箇条書きで貼る）

上の業務のうち、AIに任せられそうな作業を3つ選んで、理由を一言ずつ添えて。人が判断したほうがいい作業も、別に挙げて。
③ 「こんなことができたら」を仕分け
次のメモを「今すぐできそう」「少し工夫が必要」「将来やりたい」の3つに分けて。
（ここに、思いついたアイデアのメモを貼る）
④ 1週間で試す作戦
整理した中から1つだけ選んで、1週間で試すための小さな進め方を、3ステップで提案して。

つまづきポイント＆コツ

  • 完璧なリストを作ろうとする → 手が止まる
  • 最初から大きなことを狙う → 続かない

⭕ 気づいたときに、一言ずつメモするだけでOK。大きなものより、毎日の小さな面倒から始めると成果が出やすいです

STEP 03Claude Code / Codex

AIエージェント — 小さな作業を、任せてみる

このステップでできるようになること

  • チャットAIとAIエージェントの違いが分かる
  • 簡単な作業を、目的だけ伝えて進めてもらえる

チャットAIとAIエージェント、何が違う？

チャットAIは、聞いたことに「答えてくれる」AI。AIエージェントは、目的を伝えると、AIが自分で手順を考えて、作業まで進めてくれるAIです。ただし、AIエージェントは「司令官」のような存在。「何をしてほしいか」を決めて指示するのは、いつもご自身です。AIエージェントは、パソコンの中の「フォルダ（ファイルを入れておく場所）」を見て、作業をしてくれます。まずは小さな作業から、一緒に試してみましょう。

まずは Claude Code か Codex から1つ。画面共有しながら、一緒に進めていきます。

やってみよう｜プロンプト例3つ

使い方は、この3ステップです

① 下のカードの「コピー」を押す
② AIの入力欄に貼り付ける（Macは Command＋V、Windowsは Ctrl＋V）
③ （　）の部分を、ご自身の内容に書き換えて、送信する

最初は「元のファイルは変更しないで」と添えておくと安心。AIがやった作業は、必ずご自身の目で確かめます。

① 出品リストの形をそろえる
このフォルダに、出品したいカードの一覧（Excelやスプレッドシートの表のファイル）がある。列名をそろえて、カード名・状態・価格・枚数の4列だけの新しいファイルを作って。元のファイルは変更しないで。
② 在庫の集計
このフォルダの在庫表を読んで、カード名ごとの枚数と、合計の仕入れ金額を一覧にまとめて。計算の考え方も、短く説明して。
③ 進め方を先に確認する
これから、出品文をまとめて作る作業をお願いしたい。始める前に、必要な情報と進め方の案を、3つの質問と一緒に提案して。

つまづきポイント＆コツ

  • いきなり大きな作業を任せる → 失敗したときにやり直しが大変
  • AIの結果を、確認せずに使う → 数字や内容のズレに気づけない

⭕ 小さく任せて、結果を確認して、「ここ直して」と伝えながら、少しずつ進めましょう

STEP 04Claude Code / Codex

スキル作成 — よく使う作業を、AIに覚えてもらう

このステップでできるようになること

  • 毎回の定型作業を、1つのスキルにして、一言で呼び出せる
  • 「1作業＝1スキル」で、小さく作れる

「スキル」ってなに？

毎回ゼロから指示せず、「この作業はいつもこうやる」という手順を、AIに登録しておくことです。一度作れば、「この商品で出品文を作って」の一言で、同じ品質の作業が返ってきます。ポケカの海外販売なら、出品文・発送連絡・問い合わせ返信が、スキルにしやすい作業です。

やってみよう｜プロンプト例3つ

使い方は、この3ステップです

① 下のカードの「コピー」を押す
② AIの入力欄に貼り付ける（Macは Command＋V、Windowsは Ctrl＋V）
③ （　）の部分を、ご自身の内容に書き換えて、送信する

まず「やり方」を言葉にして渡して、スキルとして保存。次からは一言で呼び出します。

① 出品文を作るスキル
商品の情報（カード名・状態・特徴）を渡すと、海外のバイヤー向けの英語の出品文を作るスキルを作りたい。
構成は「タイトル／状態の説明／発送について／お礼の一言」の4つ。
丁寧で簡潔に。傷の説明は正直に書く、という決まりも入れて。
② 発送のお知らせを作るスキル
追跡番号を渡すと、発送を知らせる英語のメッセージを作るスキルを作って。短くて、親しみやすい口調で。
③ 問い合わせ返信のスキル
バイヤーからの質問を貼ると、丁寧な英語の返信の下書きと、日本語の要点を出してくれるスキルを作って。返信は「お礼→回答→次の案内→結び」の流れで。

つまづきポイント＆コツ

  • いきなり大きな自動化を狙う → 複雑すぎて動かない
  • お客様の本名や住所を、そのまま例文に入れる → 情報が残ってしまう

⭕ 「やり方」を言葉にするのが9割。人に教えるつもりで書き出しましょう。例文は、架空の名前にしておくと安心です

STEP 05Claude Code / Codex

ツール作成 — 計算がラクになる、小さなツールを作る

このステップでできるようになること

  • ダブルクリックで開ける、小さなツールを作れる
  • 毎回の利益計算を、ツールにできる

最後はなぜ「ツール作成」？

ここまでの成果物に続いて、最後は「ご自身がすぐ使えるもの」を作ります。今は「○○なツールを、ブラウザで開けるHTMLファイル1つで作って」と頼むだけで、コードが書けなくても形になります。ポケカの販売では、利益の計算が毎回の手間になりやすいので、ツールにするのにぴったりです。

⚙️ このステップで使うAI
Claude Code か Codex。保存して開くだけで動きます。
Claude CodeをダウンロードCodexを開く

やってみよう｜プロンプト例3つ

使い方は、この3ステップです

① 下のカードの「コピー」を押す
② AIの入力欄に貼り付ける（Macは Command＋V、Windowsは Ctrl＋V）
③ （　）の部分を、ご自身の内容に書き換えて、送信する

ポイントは「HTMLファイル1つで作って」と添えること。1つにまとまっていると、保存して、ダブルクリックで開くだけで動きます。

① 利益の計算ツール
ポケモンカード販売の利益計算ツールを、ブラウザで開けるHTMLファイル1つで作って。
・入力：仕入れ価格、販売価格、販売の手数料率（%）、送料、為替レート
・出力：1枚あたりの利益と、利益率
・手数料率と為替は、あとから変えられるように入力欄にして。
・スマホでも見やすい、シンプルなデザインで。
② 価格の比較表
カード名と、複数の販売価格を入力すると、いちばん安い価格と平均を表示するツールを、ブラウザで開けるHTMLファイル1つで作って。
③ 出品前のチェックリスト
出品前に確認する項目（写真・状態・価格・送料・説明文）をチェックできるツールを、ブラウザで開けるHTMLファイル1つで作って。全部チェックしたら「出品OK」と表示して。

つまづきポイント＆コツ

  • 手数料率や為替を、ツールの中に固定する → 変わったときに合わなくなる
  • 完璧を求める → いつまでも完成しない

⭕ 手数料・為替・送料は、入力欄にして、最新の数字を入れましょう。エラーが出たら、そのまま貼って「直して」でOK。まずは「動いた！」を大事に

数字は最新を確認手数料・為替・送料のルールは、各サービスや各国の最新の案内に従ってください。
